# Import games

## Build a database

1. Open **Database › Import** and choose your PGN files.
2. Set your name under **Settings › Databases** so Fast can identify your games.
3. Open any database game to analyse it in its own Analyse tab.

## Open and save single files

| Menu     | Use it to                      |
| -------- | ------------------------------ |
| **File** | Open or save PGN and FEN files |
| **Edit** | Copy or paste PGN and FEN      |

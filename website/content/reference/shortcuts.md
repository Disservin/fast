# Keyboard shortcuts

- Change, clear or reset any shortcut under **Settings › Keyboard shortcuts**. A key already used
  by another action moves to the new one.
- `Ctrl` is `Cmd` on macOS.
- Single-key shortcuts work in Analyse while no text field has focus.

## Moves and board

| Key          | Action                                                             |
| ------------ | ------------------------------------------------------------------ |
| `←` `→`      | Previous / next move (forward returns into the line you came from) |
| `Home` `End` | Start of game / end of line                                        |
| `F`          | Flip board                                                         |

## Engine

| Key            | Action                       |
| -------------- | ---------------------------- |
| `Space`        | Engine on / off              |
| `P`            | Pause / resume the search    |
| `B`            | Analyse the game backwards   |
| `[` `]`        | Fewer / more lines (MultiPV) |
| `Ctrl+Shift+L` | Engine output window         |

## Display

| Key | Action                     |
| --- | -------------------------- |
| `A` | All moves                  |
| `R` | Quality arrows             |
| `D` | Sort lines by eval / depth |
| `G` | Next graph                 |
| `I` | Table / inline scoresheet  |

## Games and files

| Key                             | Action                         |
| ------------------------------- | ------------------------------ |
| `Ctrl+N` / `Ctrl+O`             | New game / open PGN or FEN     |
| `Ctrl+S` / `Ctrl+Shift+S`       | Save to My games / save as PGN |
| `Ctrl+Shift+V`                  | Paste FEN or PGN               |
| `Ctrl+Shift+F` / `Ctrl+Shift+P` | Copy FEN / copy PGN            |

## App

| Key               | Action                                                         |
| ----------------- | -------------------------------------------------------------- |
| `Ctrl+K`          | Search (a FEN opens in Analyse, anything else filters players) |
| `Ctrl+1`…`Ctrl+4` | Analyse, Database, Train, Play                                 |
| `Ctrl+,`          | Settings                                                       |
| `Ctrl+Q`          | Quit                                                           |

Tab shortcuts are listed under [Workspace tabs](../workspace/tabs.md).

## Documentation search

On this website, `Ctrl/Cmd+K` focuses the search field. `Escape` clears the search and returns
to the selected guide.

# Engine tournaments

Run engine matches with fastchess and follow the games on live boards.

## Opening books

Tournament setup has a searchable list of
[Stockfish opening books](https://github.com/official-stockfish/books).

- `UHO_Lichess_4852_v1.epd` is selected by default and recommended.
- Books download on first use and are then cached for offline use.
- **No book** starts every game from the initial position.
- **Custom file…** uses a local EPD or PGN file.
